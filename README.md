## 🚀 Featured Projects

### 1. [FraudStream](https://github.com/bidhurath2005-bit/FraudStream)
**Financial Fraud Detection & Risk Intelligence Platform**

An end-to-end streaming fraud detection platform built using synthetic payment transactions.

- **Streaming:** Apache Kafka and Spark Structured Streaming with stateful feature engineering and checkpoint recovery.
- **Machine Learning:** XGBoost and Isolation Forest combined with explainable risk rules.
- **Backend:** FastAPI, PostgreSQL and Redis.
- **Frontend:** React and TypeScript analyst dashboard.
- **Analyst workflow:** Alert management, investigations, model monitoring, reporting and audit trails.
- **Engineering:** Docker Compose, automated testing, CI/CD, security checks and backup/restore verification.

**Technologies:** Python, Kafka, Spark, XGBoost, FastAPI, React, PostgreSQL, Redis, Docker.

*Note: Uses synthetic data. Model metrics do not establish real-world fraud detection performance.*

### 2. [FederatedX](https://github.com/bidhurath2005-bit/FederatedX)
**Privacy-Preserving Federated Machine Learning Platform**

A federated learning platform for collaborative model training without sharing raw client datasets.

- Flower-based federated learning orchestration.
- FedAvg, FedProx and FedAdam aggregation algorithms.
- Differential privacy using Opacus DP-SGD.
- Secure aggregation with SecAgg+.
- FastAPI control plane and React dashboard.
- Client management, training monitoring and audit logs.

**Technologies:** Python, PyTorch, Flower, Opacus, FastAPI, React, PostgreSQL, Redis.

### 3. MarketMind India
**AI-Powered Indian Stock Market Research & Intelligence Platform**

A research-oriented platform for discovering, evaluating and analysing Indian stock market opportunities.

- Multi-factor stock screening and reliability-aware scoring.
- Historical backtesting with transaction costs.
- Market regime detection and signal tracking.
- AI Research Copilot and proactive Market Scout.
- Portfolio risk investigation and audit trails.

**Technologies:** Python, FastAPI, React, PostgreSQL, Redis, Docker.

*Research limitation: The current platform uses synthetic data and has not established real-market performance.*
